Fare un backup

Studio → Backup e ripristino → Crea un backup, poi salva il file in File o iCloud Drive. Tutto vive sul dispositivo: quella sarà la tua unica copia.

Passare a un telefono nuovo

Fai il backup sul vecchio, salvalo dove puoi raggiungerlo, e sul nuovo vai su Studio → Backup e ripristino → Ripristina da un file.

Cancellare i dati di un cliente

Apri il cliente, Modifica, Elimina cliente. Scheda, firme e foto del documento se ne vanno insieme. È la cancellazione che un cliente può chiedere.

Cambiare il testo di consenso

Studio → Modelli di consenso. Modificare alza la versione; i moduli già firmati mantengono la loro.

Ripristinare un acquisto

Studio → Ripristina acquisti, con l'Apple ID usato per comprare.
