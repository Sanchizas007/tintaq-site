Make a backup

Studio → Backup and restore → Create a backup, then save the file to Files or iCloud Drive. Everything lives on the device, so this is the only copy you will have.

Move to a new phone

Make a backup on the old device, save it somewhere you can reach, then Studio → Backup and restore → Restore from a file on the new one.

Delete a client's data

Open the client, Edit, Delete client. The record, the signatures and the ID photo go together. This is the erasure a client can ask for.

Change the consent wording

Studio → Consent templates. Editing raises the version; forms already signed keep the wording they were signed on.

Restore a purchase

Studio → Restore purchases, with the Apple ID you bought it on.
