与众不同之处

客户数据留在手机里

健康回答和证件照片留在应用内，由 iOS 加密，锁在面容 ID 之后。无需创建账户，也没有保管您客户档案的服务器。没有信号也能用。

签名时文字即被固定

同意书只有在您能证明客户实际读了什么时才有意义。之后编辑模板会提升版本号，绝不会改动已经签署的同意书。

放心把手机交出去

客户模式会隐藏其他所有客户的记录，任何人离开同意书都需要面容 ID。

批号写进文件

墨水和针的批次会写进 PDF，因为这是卫生检查人员最先问的事。

一次操作的流程

  1. 选择客户，或在二十秒内添加。
  2. 选择同意书：纹身、穿孔、补色，或您自己写的。
  3. 记录项目、人形图上的部位，以及您打开的批次。
  4. 把手机交给客户。客户回答健康问题、出示证件、阅读文字并签名。
  5. 面容 ID 把手机交还给您。核对被标记的回答，保存，PDF 就完成了。

工作室常问的问题

客户的数据存在哪里？

在设备上，存放于应用自己的容器中，由 iOS 加密并锁在面容 ID 之后。客户数据不会发送到任何地方——Tintaq 没有账户，也没有为此运行服务器。只有 Pro 的购买记录和一个匿名的广告代码会送达 RevenueCat，隐私政策对此有说明。

手机丢了怎么办？

只存在本地意味着手机丢了档案也就丢了，所以 Tintaq 可以生成加密的备份文件，供您保存在“文件”或 iCloud 云盘中。请定期备份。

手指签名有效吗？

在大多数地方，只要能证明谁签的、读了什么、何时签的，电子签名就有效。Tintaq 会把这三项都保存在 PDF 中。这是否符合您当地的规定，请咨询您所在国家的律师。

同意书模板经过法律认可吗？

没有。它们是写得很好的起点，不是法律意见。声称一个应用能给您一份在所有国家都合规的文件的人，是在推销什么。请阅读模板，修改需要修改的地方，并在当地核实。

未满 18 岁的客户可以签名吗？

Tintaq 会根据出生日期计算年龄，客户未满 18 岁时会启用监护人签名。能否为其纹身，取决于您所在的国家和地区。

我必须保存证件照片吗？

不必。您可以只记录证件已核验、证件类型和末尾数字，而不保存任何图像——在不允许保存扫描件的地方，这是更轻便的选择。

能在 iPad 上用吗？

能。很多工作室会把 iPad 递给客户签名，应用为两种设备都做了设计。
