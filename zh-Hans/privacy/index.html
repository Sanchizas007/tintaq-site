隐私政策

简而言之

Tintaq 没有账户，也没有自己的服务器，永远看不到您客户的数据。您录入的关于客户的一切都留在您的设备上。离开设备的只有两样，下文都有说明：购买 Pro，以及每次安装一次的匿名 Apple Ads 代码。

应用保存什么，存在哪里

客户姓名和联系方式、健康问题的回答、您选择拍摄时的身份证件照片、人形图上的绘制、签名，以及生成的 PDF。所有这些都在您设备上应用自己的存储空间里，受 iOS 文件加密保护；如果您保持开启，还受面容 ID 或密码保护。

什么会离开设备

您自己发送的内容：您分享、打印或用邮件发送的 PDF，以及您保存到“文件”或 iCloud 云盘的备份文件。它们会去往您发送的地方，适用 Apple 或您邮件服务商的条款，而不是我们的。除此之外，只有下文说明的两样。

到店前发送的表单

客户可以在到店前，在网页上填写个人信息和健康问题的回答。该页面是 GitHub Pages 上的静态文件：它在客户自己的浏览器中运行，工作室的问题随链接中 # 之后的部分传递（浏览器从不把这部分发送给服务器），客户输入的任何内容都不会发送给我们或任何服务器。回答由客户自己通过其选择的渠道，以链接或二维码的形式发回给工作室——因此这条消息的隐私取决于客户用来发送它的应用。只有当纹身师在 Tintaq 中打开并确认后，这些回答才会成为一条记录。

我们收集什么

不收集任何关于您客户的信息，也不收集您如何使用应用的信息：没有账户、没有使用分析、没有崩溃报告、应用内没有广告。应用里唯一的第三方是 RevenueCat，它会收到下文所述的购买数据和广告活动数据。App Store 隐私标签恰好列出这两类数据——购买和广告数据——都不与您关联，也都不用于跟踪。

相机、照片和面容 ID

相机只用于为同意书拍摄身份证件；照片直接进入应用，绝不进入相册。图库访问只在您选择现有图片或工作室标志时使用。面容 ID 只用于解锁应用和退出客户模式；生物识别数据绝不会到达应用——iOS 只回答是或否。

购买与 RevenueCat

Pro 通过 App Store 销售，是否拥有由您的设备决定：Tintaq 询问 Apple 这个 Apple ID 是否拥有解锁，并得到是或否的答复。为了跟踪订阅，应用还会把您的购买告知 RevenueCat——一项处理应用内购买的服务。RevenueCat 会收到来自 Apple 的购买凭据和交易详情、它自己生成的匿名应用用户 ID，以及任何网络请求都会附带的技术数据，例如 IP 地址、设备型号、系统版本、语言和国家或地区。它绝不会收到关于您客户的任何信息，也不会收到您录入的任何内容。我们无法据此得知您是谁，RevenueCat 也不会用这些数据在其他公司的应用或网站上跟踪您。RevenueCat 自己的政策（revenuecat.com/privacy）说明了它如何处理这些数据。我们永远看不到您的姓名、银行卡或地址。

Apple Ads 归因

无论您是否来自广告，应用都会向 Apple 请求一个归因代码——它不说明您是谁——并在每次安装时仅一次，连同匿名应用用户 ID 一起交给 RevenueCat。如果您是在 App Store 点按我们的广告（Apple Ads）后安装了 Tintaq，RevenueCat 会用这个代码向 Apple 询问该广告属于哪个广告活动、广告组和关键词，并与同一个 ID 一并保存，以便我们了解哪些广告带来了购买。如果您并非来自广告，Apple 不会返回任何广告活动。Tintaq 不读取您的广告标识符（IDFA），也不会弹出跟踪许可请求，因为没有任何内容会与其他公司的应用或网站的数据合并。上文提到的 RevenueCat 政策同样适用于这些数据。

您客户的权利

根据《个人信息保护法》和 GDPR，工作室是其客户数据的处理者（控制者）。由于数据从不会到达我们这里，Tintaq 只是工具，而不是受托处理者。客户要求删除时，请在应用中删除该客户：记录、签名和证件照片会一并删除。

儿童

Tintaq 是供专业人士使用的工具，不面向儿童。未满 18 岁的客户仅在法律允许操作的情况下，连同监护人签名一并记录。

变更

如果本政策有变，下方日期会随之更新，重大变更会在应用的版本说明中提及。
