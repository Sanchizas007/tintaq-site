隱私權政策

簡單來說

Tintaq 沒有帳號，也沒有自己的伺服器，永遠看不到您客戶的資料。您輸入的關於客戶的一切都留在您的裝置上。離開裝置的只有兩樣，下文都有說明：購買 Pro，以及每次安裝一次的匿名 Apple Ads 代碼。

App 保存什麼，存在哪裡

客戶姓名與聯絡方式、健康問題的回答、您選擇拍攝時的身分證件照片、人形圖上的繪製、簽名，以及製作出的 PDF。這些都在您裝置上 App 自己的儲存空間裡，受 iOS 檔案加密保護；如果您保持開啟，還受 Face ID 或密碼保護。

什麼會離開裝置

您自己傳送的內容：您分享、列印或用郵件寄出的 PDF，以及您儲存到「檔案」或 iCloud 雲碟的備份檔。它們會前往您傳送的地方，適用 Apple 或您郵件服務商的條款，而不是我們的。除此之外，只有下文說明的兩樣。

到店前傳送的表單

客戶可以在到店前，在網頁上填寫個人資料與健康問題的回答。該頁面是 GitHub Pages 上的靜態檔案：它在客戶自己的瀏覽器中執行，工作室的問題隨連結中 # 之後的部分傳遞（瀏覽器從不把這部分傳送給伺服器），客戶輸入的任何內容都不會傳送給我們或任何伺服器。回答由客戶自己透過其選擇的管道，以連結或 QR Code 的形式傳回給工作室——因此這則訊息的隱私取決於客戶用來傳送它的 App。只有當刺青師在 Tintaq 中開啟並確認後，這些回答才會成為一筆紀錄。

我們蒐集什麼

不蒐集任何關於您客戶的資訊，也不蒐集您如何使用 App 的資訊：沒有帳號、沒有使用分析、沒有當機報告、App 內沒有廣告。App 裡唯一的第三方是 RevenueCat，它會收到下文所述的購買資料與廣告活動資料。App Store 隱私權標籤恰好列出這兩類資料——購買與廣告資料——都不與您連結，也都不用於追蹤。

相機、照片與 Face ID

相機只用來為同意書拍攝身分證件；照片直接進入 App，絕不會進入相簿。照片圖庫存取只在您選擇現有圖片或工作室標誌時使用。Face ID 只用來解鎖 App 與離開客戶模式；生物辨識資料絕不會傳到 App——iOS 只回答是或否。

購買與 RevenueCat

Pro 透過 App Store 銷售，是否擁有由您的裝置決定：Tintaq 詢問 Apple 這個 Apple ID 是否擁有解鎖，並得到是或否的答覆。為了追蹤訂閱，App 還會把您的購買告知 RevenueCat——一項處理 App 內購買的服務。RevenueCat 會收到來自 Apple 的購買憑證與交易詳情、它自己產生的匿名 App 使用者 ID，以及任何網路請求都會附帶的技術資料，例如 IP 位址、裝置型號、系統版本、語言與國家或地區。它絕不會收到關於您客戶的任何資訊，也不會收到您輸入的任何內容。我們無法據此得知您是誰，RevenueCat 也不會用這些資料在其他公司的 App 或網站上追蹤您。RevenueCat 自己的政策（revenuecat.com/privacy）說明了它如何處理這些資料。我們永遠看不到您的姓名、信用卡或地址。

Apple Ads 歸因

無論您是否來自廣告，App 都會向 Apple 要求一個歸因代碼——它不說明您是誰——並在每次安裝時僅一次，連同匿名 App 使用者 ID 一起交給 RevenueCat。如果您是在 App Store 點按我們的廣告（Apple Ads）後安裝了 Tintaq，RevenueCat 會用這個代碼向 Apple 詢問該廣告屬於哪個廣告活動、廣告群組與關鍵字，並與同一個 ID 一併保存，以便我們了解哪些廣告帶來了購買。如果您並非來自廣告，Apple 不會回傳任何廣告活動。Tintaq 不讀取您的廣告識別碼（IDFA），也不會跳出追蹤許可請求，因為沒有任何內容會與其他公司的 App 或網站的資料合併。上文提到的 RevenueCat 政策同樣適用於這些資料。

您客戶的權利

依《個人資料保護法》與 GDPR，工作室是其客戶資料的蒐集者（控制者）。由於資料從不會傳到我們這裡，Tintaq 只是工具，而非受託處理者。客戶要求刪除時，請在 App 中刪除該客戶：紀錄、簽名與證件照片會一併刪除。

兒童

Tintaq 是供專業人士使用的工具，並非以兒童為對象。未滿 18 歲的客戶僅在法律允許施作的情況下，連同監護人簽名一併紀錄。
