與眾不同之處

什麼都不上傳

健康回答與證件照片留在 App 裡，由 iOS 加密，並受 Face ID 保護。不用建立帳號，也不必信任任何伺服器。沒有訊號也能使用。

簽名時文字即被固定

同意書只有在您能證明客戶實際讀了什麼時才有意義。日後編輯範本會提高版本號，絕不會更動已簽署的同意書。

放心把手機交出去

客戶模式會隱藏其他所有客戶的紀錄，任何人離開同意書都需要 Face ID。

批號寫進文件

墨水與針的批次會寫進 PDF，因為這是衛生稽查人員最先問的事。

繁體中文、簡體中文、英文、德文、法文、西班牙文、義大利文、葡萄牙文、荷蘭文、波蘭文、俄文、土耳其文、日文與韓文——App、同意書範本與護理說明都有。

您的文字，您的標誌

範本只是起點。依您的國家與工作室改寫，並把標誌放進頁首。

一次施作的流程

  1. 選擇客戶，或在二十秒內新增。
  2. 選擇同意書：刺青、穿洞、補色，或您自己寫的。
  3. 紀錄施作項目、人形圖上的部位，以及您打開的批次。
  4. 把手機交給客戶。客戶回答健康問題、出示證件、閱讀文字並簽名。
  5. Face ID 把手機交還給您。確認被標示的回答，儲存，PDF 就完成了。

價格

工作室常問的問題

客戶的資料存在哪裡？

存在裝置上，App 自己的儲存空間裡，由 iOS 加密並用 Face ID 鎖住。不會傳送到任何地方——Tintaq 沒有伺服器，也沒有帳號。

手機遺失怎麼辦？

只存在本機代表手機遺失檔案也跟著遺失，所以 Tintaq 可以製作加密的備份檔，讓您存放在「檔案」或 iCloud 雲碟。請定期備份。

手指簽名有效嗎？

在大多數地方，只要能證明誰簽的、讀了什麼、何時簽的，電子簽名就有效。Tintaq 會把這三項都保存在 PDF 中。這是否符合您當地的規定，請洽詢您所在國家的律師。

同意書範本經過法律認可嗎？

沒有。它們是寫得很好的起點，不是法律意見。宣稱某個 App 能給您一份在所有國家都合規的文件的人，是在推銷什麼。請閱讀範本，修改需要修改的地方，並在當地確認。

未滿 18 歲的客戶可以簽名嗎？

Tintaq 會依出生日期計算年齡，客戶未滿 18 歲時會開啟監護人簽名。能否為其刺青，取決於您所在的國家與地區。

我必須保存證件照片嗎？

不必。您可以只紀錄證件已核對、證件類型與末幾碼，而不保存任何影像——在不允許保存掃描檔的地方，這是較輕便的選擇。

能在 iPad 上使用嗎？

可以。很多工作室會把 iPad 遞給客戶簽名，App 為兩種裝置都做了設計。
